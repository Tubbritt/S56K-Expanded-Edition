# S56K Expanded Edition v1

**A new sampling workflow for the AKAI S5000 and S6000.** Expanded Edition adds automatic capture and optional loop preparation while keeping programs and samples in RAM until you choose to save them.

## Auto Sample

Create and name an empty program, then open **Program Tools → Auto Sample**. Choose a note range, spacing and timing; Auto Sample plays the connected instrument over MIDI, records its audio, names the samples and assigns them to the current program.

- **Musical note names** for the low and high notes.
- **MIDI OUT A/B** and an adjustable MIDI channel.
- **One to four velocity layers**, with calculated playback ranges.
- **Native recording levels** and mono/stereo capture selection.
- **Adjustable start threshold** and configurable quiet detection.
- **Progress and cancellation**, with completed sample assignments retained.

## Capture the time you need

**AUTO END** offers three explicit choices:

| Mode | Behavior |
| --- | --- |
| **OFF** | Records the full note and tail durations. |
| **TAIL ONLY** | Keeps the full held note; confirmed quiet can finish the release tail early. |
| **NOTE + TAIL** | Confirmed quiet can shorten either phase, subject to the minimum-time settings. |

The REC SETUP page shows the controls relevant to the selected mode. Its end detector uses the sampler's native coarse meter scale; **METER FLOOR** is not a calibrated dBFS value.

## Optional Auto Loop

Choose loop-start and loop-end percentages within the held part of the recording. Enable **AKAI AUTO FIND** to refine those positions locally, and apply the sampler's native **CROSSFADE** with LINEAR, LOG or SINE shape.

**CROP AFTER LOOP** retains the attack through the loop end and the required interpolation margin. With cropping off, a successfully processed loop keeps the held-note recording and removes the external instrument's release tail. An unsuccessful loop leaves the original recording available for review.

Auto Find is a local refinement of the selected positions, not an exhaustive search through every possible loop. Audition the result: evolving, noisy or heavily modulated sounds may need manual editing.

## A clearer interface

Full-size setup fields, consistent borders and contextual controls keep the pages focused. The VELOCITIES page shows only the active layers. Loop and crossfade options appear when enabled. Auto Sample pages contain no release-number label.

The startup screen carries a shared CPU/circuit graphic, model-specific **S5000 EX** or **S6000 EX** lettering, and **EXPANDED EDITION v1**. The official AKAI OS/settings/protocol identity remains **2.14**; the visible edition name is separate.

## Saving stays manual

Auto Sample populates the current program in RAM. Use the ordinary **SAVE** page to save the program **with its samples** before switching off. There is no automatic disk-saving step.

## Compatibility and practical limits

- The firmware targets the S5000 and S6000. USB is not required for the sampling workflow.
- Leave generous free sample RAM for recordings and temporary loop-processing copies. Long notes, stereo and more velocity layers increase memory demand.
- Avoid simultaneous sample editing through ak.Sys or SysEx while Auto Loop is running.
- The extension reserves some CPU memory, which can reduce maximum program/sample-metadata capacity. Sample RAM is a separate resource.
- There is no added second flash bank or automatic rollback. Flashing remains the user's choice and risk under the [disclaimer](../DISCLAIMER.md).

The image passed 15 firmware software verification suites. Earlier Auto Sample versions have user-reported operation on both models, and an earlier corrected floppy installer was successfully flashed and rebooted. On 23 October 2026, the user confirmed a complete downgrade to original Akai v2.14 and upgrade back to this Expanded image using the standalone Windows USB updater, following the reboot and visual-check procedure. The established USB test setup is an S6000 and Windows 11 Pro 25H2. This does not establish S5000 USB or ak.Sys installation coverage.
