# S56K Expanded Edition V1.1

**Released 2 November 2026.** This update improves Auto Sample's looping, release handling, input monitoring and reliability on the AKAI S5000 and S6000.

## Changes from V1

1. **Fixed release tails being removed with cropping switched off.** With **CROP AFTER LOOP OFF**, successful loop processing now preserves the attack, held note and complete recorded release, including fading notes, reverb and other effects. Previously, it removed the release even with cropping off.
2. **CROP AFTER LOOP now defaults to OFF.** Keeping the full recording is the default. Turning cropping ON still deliberately removes audio after the loop end, retaining Akai's small playback margin.
3. **Added PLAY MODE to LOOP SETUP at F6.** **UNTIL RELEASE**, the default, loops while you hold the playback key. **IN RELEASE** allows looping to continue after you release it, under the amplitude envelope. Previously, Auto Sample always selected IN RELEASE. The control appears when AUTO LOOP is ON.
4. **Fixed program settings overriding the chosen loop mode.** Newly assigned zones use **AS SAMPLE**, so they follow the sample's playback mode instead of an inherited zone override.
5. **Improved crossfade acceptance.** A positive crossfade can now process loop endpoints that do not already closely match. Previously, the initial checks could reject a loop before crossfade had an opportunity to smooth it. Stricter seam checks remain when no crossfade is applied; results still need listening checks.
6. **Protected release tails during crossfading.** With cropping OFF, crossfade processing is limited to protect all audio recorded after Note Off. The fade is shortened when necessary, so its effective length can be smaller than the requested percentage. Moving the loop end earlier can leave more space for a longer fade.
7. **Added input monitoring within Auto Sample.** Monitoring is enabled during setup and capture, with proper handover when entering REC LEVELS, starting recording or leaving Auto Sample. Previous monitoring preferences are restored. Monitoring can pause during loop processing and between recordings.
8. **Fixed cancellation immediately after START.** Cancelling while the recorder was still starting could leave Auto Sample waiting for it to stop. The stop request is now completed once the recorder becomes active, within the existing timeout.
9. **Fixed error messages being replaced by a stuck STOPPING display.** Restart-required errors remain visible. The inactive Cancel button is removed, and Cancel/Exit no longer hides the explanation.
10. **Improved explanations when a sampling run stops.** Setup, routing, recording and MIDI failures retain their original explanation after cleanup. Leaving the Auto Sample page during a run is identified explicitly. A more serious cleanup problem can still require a restart.
11. **Improved handling of recoverable loop-processing failures.** Certain failures that previously appeared as user cancellation now keep the original recording, mark it for **REVIEW**, and continue when it is confirmed that the edit never started.
12. **Clearer handling of uncertain loop-processing failures.** If the sampler cannot confirm the processing state, the run stops with a specific error. It is not reported as user Cancel and is not automatically retried.
13. **Added loop diagnostics.** The progress screen can show **LAST LOOP**, the processing stage that needs attention, and an Akai error code when available. Include the whole screen in a problem report.
14. **Updated the startup caption.** Both model paths display **EXPANDED EDITION V1.1**, with the existing S5000 EX / S6000 EX artwork. The underlying Akai OS/settings/protocol identity remains **2.14**.
15. **Expanded software verification.** Added checks for recorder cancellation, monitoring, memory-allocation behavior and release preservation. All 16 software-check suites passed for this exact BIN, followed by independent review.

## Practical notes

- The update reserves **4 KiB more CPU RAM than V1**. Sample RAM capacity is unchanged. Leave ample free sample RAM for recording and temporary loop-processing copies.
- The program's amplitude envelope still determines how much retained release audio is heard after releasing a playback key.
- Avoid simultaneous external sample editing through ak.Sys, the Editor or SysEx while Auto Sample is running.
- Completed programs and samples remain in RAM. Save them manually through the normal **SAVE** page.
- Native memory allocation can wait when resources are exhausted. This update does not replace Akai's allocator or guarantee recovery from every low-memory condition.
- The original report's unexplained STOPPED event was not conclusively reproduced. The fixes above address the confirmed code paths; they do not establish that every possible stop has the same cause.

## Verification and installation

On **2 November 2026**, the owner reported **“Flashing worked”** after receiving this exact V1.1 BIN and the floppy flash-test procedure. The sampler model was not restated in that confirmation; it does not separately establish results on both models or USB installation. The preceding private build was reported to be working very well. V1.1 differs from it only in the boot caption and its text pointer.

The software checks cover boot drawing, memory layout, recording control, monitoring, native loop processing and installer behavior under controlled test conditions. Physical flashing is supported by the owner's report, not an independent flash readback or a guarantee for every machine. See [compatibility and test scope](../docs/COMPATIBILITY.md).

Verify the downloaded file and the copy on your floppy. On the actual boot where you intend to install, confirm **EXPANDED EDITION V1.1** before choosing **YES** at **Write Flash OS**. After successful installation, remove the floppy and restart to check that V1.1 is stored in flash. Follow the [full instructions](../docs/INSTALLATION.md).
