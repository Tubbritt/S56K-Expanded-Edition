# Keeping this a release home

This repository is for Personal Edition release information, user guides and visual assets. It does not host firmware development source, build tools, disassembly or research material.

Documentation corrections and clear device observations are welcome through [Issues](https://github.com/Tubbritt/S56K-Personal-Edition/issues). For device feedback, include the sampler model, exact release filename, how it was loaded, relevant settings, expected behaviour and what happened. A screen photograph can help describe a visual issue.

Keep committed files to Markdown documents, images and PDF guides. The repository ignore rules help exclude executable files, firmware, archives and development code. Approved firmware downloads belong in GitHub Release attachments and are published only when the project owner authorises the specific release.

No firmware is currently published here.
