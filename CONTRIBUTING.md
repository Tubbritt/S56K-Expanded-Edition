# Feedback & documentation

S56K Expanded Edition's repository is home to release information, user guides and visual assets. Firmware development source, build tools, disassembly and research material are maintained separately.

## Report an issue

Documentation corrections and clear device observations are welcome through [Issues](https://github.com/Tubbritt/S56K-Personal-Edition/issues). Include:

- Sampler model and the exact firmware version or file checksum.
- How it was loaded or installed: temporary floppy boot, permanent floppy flash or another method.
- Relevant settings, what you expected and what happened.
- A screen photograph where it helps explain the issue.

Do not post private information or proprietary sample libraries. For an update failure, preserve the exact displayed message and avoid describing an untested recovery procedure as a guaranteed fix.

## Repository contents

Keep committed files to documentation, images and PDF guides. The ignore rules exclude executable files, firmware, archives and development code. Firmware release attachments are published separately and only when the project owner authorizes that specific download.

Read the [flashing disclaimer](DISCLAIMER.md) and [compatibility notes](docs/COMPATIBILITY.md) before using a firmware image. Reporting a successful installation helps document that result; it does not establish safety on every device or for a different BIN.
