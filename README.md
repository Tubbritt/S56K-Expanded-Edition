**Your sampler, with new ways to capture sound.**

Personal Edition adds automatic instrument sampling and optional loop preparation to the AKAI S5000 and S6000. Choose a sound, define the notes and velocities, and build a playable program using the sampler's own recording and editing tools.

### From a sound to an instrument

Auto Sample sends notes to your external instrument, captures its audio, names the recordings and places them into your program. Choose the range and note spacing, then add up to four velocity layers for sounds that change with playing strength.

Set recording gain and mono/stereo using **REC LEVELS**. Use **AUTO END** to finish quiet tails early, or let naturally decaying notes end before their maximum duration.

### A sustain worth keeping

Choose loop positions within the held part of a recording. Optional **AKAI AUTO FIND** refines the join locally; native **CROSSFADE** offers LINEAR, LOG and SINE shapes. Crop after the loop, or retain the held-note recording.

Listen to every result. When a recording cannot pass the loop checks, the original remains available for review. This is a practical starting point for sustained instruments, with the ordinary sample editor available for finishing touches.

### Familiar hardware. A clearer workflow.

| Added capability | What it gives you |
| --- | --- |
| **Automatic note-range capture** | MIDI output A/B, musical note names and adjustable note spacing. |
| **Velocity layers** | One to four capture velocities, with automatic playback-zone mapping. |
| **Recording control** | Native input levels, mono/stereo choice and an editable start threshold. |
| **Three Auto End modes** | Full durations, quiet-tail ending, or quiet ending during both note and tail. |
| **Optional Auto Loop** | Percentage positions, local Akai Auto Find, crossfade and cropping. |
| **Progress and cancellation** | Follow each recording and keep completed assignments when stopping a run. |
| **A cleaner interface** | Consistent menu boxes, contextual controls and no version label on Auto Sample pages. |
| **Personal Edition startup** | Original model-specific S5000/S6000 graphics with a discreet PERSONAL EDITION label. |

**Saving stays in your hands.** Auto Sample builds the program in RAM. Use the normal **SAVE** page to store the program with its samples when you are happy with it.
